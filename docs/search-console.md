# Search Console の所有権確認

26ドメイン（25業種 + ポータル）を1つのコードで配信しているため、
所有権確認のタグは「配信中のホストに対応するものだけ」を出す必要がある。
よそのドメインのトークンを出すと確認は通らない。

## 手順

1. Search Console でプロパティを追加する（URLプレフィックス、`https://＜ドメイン＞/`）
2. 確認方法として「HTMLタグ」を選ぶ
3. 表示された値を `data/search-console.json` の該当ドメインの欄に貼る
4. `npm test` で書式を確認する
5. デプロイしてから Search Console の「確認」を押す

貼り方は次のどれでもよい。トークンだけ取り出して使う。

```
AbCd1234...
<meta name="google-site-verification" content="AbCd1234..." />
google-site-verification=AbCd1234...
```

## 出るもの

`app/layout.tsx` が配信中のホストを見て、そのドメインのトークンだけを
`<meta name="google-site-verification" content="...">` として全ページに出す。
欄が空のドメインではタグを出さない。対応表に無いホスト（プレビュー用URLなど）にも出さない。

## トークンを環境変数にしていない理由

このトークンは仕様上ページのHTMLに公開される値で、秘密ではない。
第三者がこれを使って所有権を主張するには、先にそのサイトを支配している必要がある。
26ドメイン・5ブランチぶんを取り違えずに扱うほうが重要なので、
リポジトリ内の対応表で管理している。

## サイトマップの送信

確認が通ったら、各ドメインで `sitemap.xml` を送信する。
中身はドメインごとに違う（美容室387URL、メンズ美容150URL、ポータル28URLなど）。

## 注意

確認はデプロイ済みのサイトに対して行われる。
DNSがまだお名前.comの取得済みページを向いているドメインでは、
タグを入れても確認は通らない。DNSの切り替えとHTTPSの有効化が先になる。
